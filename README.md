## Getting Started

Follow the instructions below to set up and run the project.

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/medium-uz.git
   ```
2. Navigate to the project directory:
   ```sh
   cd medium-uz
   ```
3. Install dependencies:
   ```sh
   npm install
   ```

### Running the Project

- For development mode:
  ```sh
  npm run dev
  ```
- For production mode:
  ```sh
  npm run prod
  ```
